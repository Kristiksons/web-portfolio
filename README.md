
# Web Portfolio

**Autors:** Kristiāns Štībelis

## Projekta apraksts
Šajā repozitorijā apkopoti mani HTML un CSS mācību darbi.

## Mapju struktūra
- `vizitkarte/` – pirmais HTML vizītkartes darbs.
- `profils/` – profila lapa ar HTML un CSS.
- `melnraksti/` – melnraksti, kas netiek pievienoti Git.

## Izmantotās tehnoloģijas
- HTML5
- CSS3
- Git
- GitHub
